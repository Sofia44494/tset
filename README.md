# RailFlow ERP

Современная ERP-система для управления железнодорожными перевозками: от заявки и
планирования маршрута до контроля парка, SLA, документов и финансов.

## Возможности

- командный центр с KPI по отправкам, SLA, выручке и рискам;
- реестр перевозок с поиском по клиентам, маршрутам, грузам и статусам;
- операционная воронка жизненного цикла перевозки;
- центр реагирования на риски и диспетчерские события;
- управление доступностью вагонного парка и плановым ТО;
- ЕРВ (Единый реестр вагонов) с паспортами вагонов и описаниями характеристик;
- мониторинг терминалов, загрузки станций и простоев;
- финансовый контур с доходностью, ставками и задолженностью;
- контроль ЭДО, актов, накладных, сертификатов и претензий.
